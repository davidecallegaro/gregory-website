What Gregory does

The workbook stays the model. Gregory keeps the record beside it.

Driver-based models live or die on their assumptions — and the assumptions live in emails, call notes, and someone’s memory. Gregory gives them a register of their own.

Register

Provenance

Every assumption carries a source, a date, an owner, and a confidence level — from exports, PDFs, call transcripts, emails, or a founder’s spoken word. Stale and unconfirmed assumptions are flagged before they become the forecast.

Cycle

Review loop

Gregory drafts the client review request from the register, not from memory, turns the reply and call transcripts into proposed cell changes with the quote behind each one, and shows you the diff. You approve, edit, or reject — item by item.

Findings

Checks

The line-by-line checks you already run by hand — hardcoded numbers inside formulas, broken references, rows that stopped reconciling — run on every cycle and come back as findings, never silent fixes.

One cycle, end to end

From “the client replied” to a model you can defend.

Register the source. The reply, the transcript, the PDF — filed against the engagement.

Extraction proposes changes. Each proposed value carries the exact quote it came from; anything that can’t be grounded in the source’s own words is flagged, not trusted.

You decide every item. Approve, edit, or reject — with the diff and the reasons in front of you.

Approved changes are applied — with a snapshot before and after, so any apply can be rolled back.

The trail is written into the workbook. Cell notes with source and status, a change note for the client, and a fresh run of the checks.

Non-negotiables

Product rules, enforced in code — not preferences.

N1

Nothing writes without approval.

The only write path runs through changes a human decided. There is no auto-apply, and no way to bypass the gate.

N2

The workbook stays yours.

Provenance uses native features — named ranges, notes, a hidden sheet. No macros, no add-in dependency. Remove Gregory and the model still opens everywhere.

N3

Excel in, Excel out.

A model lives on one platform for its whole life. Gregory never converts your file or moves it to a format your client can’t open.

N5

Client data stays where the engagement allows.

Per-engagement flags control cloud processing and AI use. Calls send the minimum text needed, and client values never appear in logs.
