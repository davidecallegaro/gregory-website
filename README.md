# gregory.work

Marketing site for Gregory — provenance, review loop, and checks for
driver-based financial models. Single static page, no build step.

Served by GitHub Pages at https://gregory.work (custom domain via `CNAME`).

**This repo is the source of truth for the page.** Edit `index.html` here and
push to `main` to deploy. There is no second copy to keep in sync: the product
repo (`davidecallegaro/project-money`) carries a pointer at `site/README.md`
and nothing else. It held a duplicate of the page until 2026-09-04, which
drifted three commits behind this one before it was removed.
